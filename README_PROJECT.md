# Eternal Sentinels - SCP Database Website

## Описание

Полнофункциональная база данных SCP объектов организации Eternal Sentinels с интерактивным чатом с MAL0 (SCP-1471) и расширенными возможностями.

## Основные функции

### 1. Интерактивный чат с MAL0
- Голосовое озвучивание ответов (Web Speech API)
- Романтическое поведение при распознавании "Палача Рока" (фраза: "Мой Лисёнок 1471")
- Контекстная память разговора
- Кодовая фраза для доступа к засекреченным досье: **"Рвать и Терзать 09.19.03"**

### 2. База данных объектов
- **18 объектов SCP**
  - 14 публичных объектов (0051-9999)
  - 4 засекреченных объекта (0000-0004) - доступны только после кодовой фразы

### 3. Интерактивные элементы
- Изображение MAL0, следующее за курсором
- Детальные досье с полной информацией об объектах
- Классификация угроз от Threat до Annihilation
- Изображения для некоторых объектов (0000, 4589, 4812)

### 4. Дизайн
- Тёмная тема в стиле SCP Foundation
- Красные акценты и неоновые эффекты
- Адаптивный дизайн для всех устройств

## Технологический стек

### Backend
- **FastAPI** (Python)
- **MongoDB** для хранения данных
- **emergentintegrations** для интеграции с OpenAI GPT-4o-mini
- **Motor** для асинхронной работы с MongoDB

### Frontend
- **React 19**
- **Axios** для API запросов
- **Web Speech API** для озвучивания
- **CSS Animations** для визуальных эффектов

## Установка и запуск

### Требования
- Python 3.11+
- Node.js 18+
- MongoDB
- Yarn

### Backend

```bash
cd backend
pip install -r requirements.txt

# Настройка .env
echo "MONGO_URL=mongodb://localhost:27017" > .env
echo "DB_NAME=eternal_sentinels" >> .env
echo "CORS_ORIGINS=*" >> .env
echo "EMERGENT_LLM_KEY=your-key-here" >> .env

# Запуск
uvicorn server:app --host 0.0.0.0 --port 8001 --reload
```

### Frontend

```bash
cd frontend
yarn install

# Настройка .env
echo "REACT_APP_BACKEND_URL=http://localhost:8001" > .env

# Запуск
yarn start
```

## API Endpoints

### Публичные объекты
```
GET /api/scp/public
```
Возвращает список всех публичных объектов SCP

### Засекреченные объекты
```
GET /api/scp/classified
```
Возвращает список засекреченных объектов (требуется авторизация через чат)

### Объект по номеру
```
GET /api/scp/{number}
```
Возвращает детальную информацию об объекте

### Чат с MAL0
```
POST /api/chat
Body: {
  "message": "Текст сообщения",
  "session_id": "уникальный ID сессии"
}
```
Отправить сообщение MAL0

### История чата
```
GET /api/chat/history/{session_id}
```
Получить историю чата

## Особенности реализации

### Кодовые фразы

1. **Доступ к засекреченным досье**: "Рвать и Терзать 09.19.03"
   - Разблокирует объекты 0000-0004
   - MAL0 подтверждает доступ

2. **Идентификация Палача Рока**: "Мой Лисёнок 1471"
   - Активирует романтическое поведение MAL0
   - Изменяет тон общения на более нежный и игривый

### Голосовое озвучивание

Используется Web Speech API для озвучивания ответов MAL0:
- Женский голос
- Настроен темп (0.9)
- Повышенная высота голоса (1.2)
- Автоматическое озвучивание всех ответов

### Визуальные эффекты

1. **Изображение, следящее за курсором**
   - Плавное следование за мышью
   - Эффект свечения
   - Анимация плавания

2. **Адаптивные карточки досье**
   - Hover эффекты
   - Плавные переходы
   - Цветовая индикация уровня угрозы

## Структура данных

### SCP Object Schema
```javascript
{
  id: string,
  number: string,          // "0000", "0051", etc.
  name: string,
  codename: string,
  threat_class: string,    // "Threat", "Hazard", "Cataclysm", etc.
  description: string,
  special_procedures: string,
  secret_data: string,
  image_url: string,
  is_classified: boolean,
  created_at: datetime
}
```

### Chat Message Schema
```javascript
{
  id: string,
  session_id: string,
  role: string,            // "user" or "assistant"
  content: string,
  is_palach_roka: boolean,
  timestamp: datetime
}
```

## Классификация угроз

1. **Threat (Угроза)** - Локальная угроза
2. **Hazard (Опасность)** - Средний уровень опасности
3. **Cataclysm (Катаклизм)** - Способны уничтожать города
4. **Collapse (Крушение)** - Угроза человечеству
5. **Apex (Предел)** - Максимальная угроза планетарного масштаба
6. **Absolute (Абсолют)** - Нарушают законы бытия
7. **Annihilation (Аннигиляция)** - Угроза существованию реальности

## Важные заметки

1. **Emergent LLM Key**: Для работы чата требуется действующий ключ API
2. **MongoDB**: База данных автоматически инициализируется при первом запуске
3. **CORS**: По умолчанию разрешены все origins (измените в production)
4. **Web Speech API**: Работает в большинстве современных браузеров (Chrome, Edge, Safari)

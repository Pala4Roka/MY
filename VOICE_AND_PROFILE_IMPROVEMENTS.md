# ТЕХНИЧЕСКОЕ ЗАДАНИЕ: Улучшение голоса MAL0 и персонализация профиля

## КОНТЕКСТ
Приложение: SCP база данных Eternal Sentinels с AI ассистентом MAL0
Текущий стек: FastAPI (Python) + React + MongoDB

---

## ЗАДАЧА 1: ЗАМЕНА ГОЛОСА ОЗВУЧКИ ЧАТА MAL0

### Текущее состояние
- MAL0 AI ассистент работает через текстовый чат
- Возможно есть базовая озвучка (TTS - Text-to-Speech)
- Нужно улучшить качество/характер голоса

### Требования к новому голосу
1. **Характер голоса:**
   - Женский голос (MAL0 - женский персонаж)
   - Загадочный, слегка мистический
   - Профессиональный, но живой
   - С легким эмоциональным окрасом

2. **Технические требования:**
   - Поддержка русского языка (основной язык приложения)
   - Высокое качество звука
   - Низкая задержка генерации
   - Возможность передачи эмоций (радость, грусть, спокойствие и т.д.)

3. **Интеграция:**
   - TTS сервис на выбор:
     * **ElevenLabs** (высокое качество, эмоциональность) - ПРИОРИТЕТ
     * OpenAI TTS (поддержка через Emergent LLM key)
     * Google Cloud TTS
     * Azure Speech Services
   - Автоматическая озвучка ответов MAL0
   - Возможность включить/выключить озвучку
   - Визуальная индикация во время проигрывания

4. **UI/UX элементы:**
   - Кнопка включения/выключения голоса в ChatInterface
   - Индикатор "MAL0 говорит" (анимация)
   - Регулировка громкости
   - Возможность остановить воспроизведение

### Файлы для модификации
- `/app/frontend/src/components/ChatInterface.js` - добавить TTS функционал
- `/app/frontend/src/components/ChatInterface.css` - стили для кнопок голоса
- `/app/backend/server.py` - возможно добавить endpoint для TTS (если используется backend)
- `/app/frontend/package.json` - добавить библиотеки для аудио

### Рекомендуемые библиотеки
**Frontend:**
- `elevenlabs` (если ElevenLabs)
- `react-speech-kit` (для базового TTS)
- `howler.js` (для управления аудио)

**Backend (опционально):**
- `elevenlabs` Python SDK
- `openai` (для OpenAI TTS через Emergent LLM key)

#### 2.1 Дополнительные поля профиля

**Backend (MongoDB):**
Добавить в коллекцию `users`:
```javascript
{
  // Существующие поля
  id: String,
  username: String,
  password_hash: String,
  clearance_level: Number,
  created_at: DateTime,
  is_active: Boolean,
  is_admin: Boolean,
  
  // НОВЫЕ ПОЛЯ
  profile: {
    avatar_url: String,           // URL аватара пользователя
    full_name: String,            // Полное имя (опционально)
    bio: String,                  // Краткая биография
    department: String,           // Отдел/подразделение
    position: String,             // Должность
    specialization: String,       // Специализация
    phone: String,                // Телефон (опционально)
    email: String,                // Email (опционально)
  },
  
  statistics: {
    total_logins: Number,         // Количество входов
    last_login: DateTime,         // Последний вход
    dossiers_viewed: Array,       // История просмотра досье
    favorite_objects: Array,      // Избранные объекты
    mal0_chats_count: Number,     // Количество диалогов с MAL0
  },
  
  preferences: {
    theme: String,                // Тема (dark/light)
    voice_enabled: Boolean,       // Озвучка MAL0 включена
    notifications: Boolean,       // Уведомления
    language: String,             // Язык (ru/en)
  }
}
```

## ТЕХНИЧЕСКИЕ ОГРАНИЧЕНИЯ

1. **Emergent LLM key** работает только с:
   - OpenAI (text & image generation)
   - Anthropic Claude (text only)
   - Google Gemini (text & Nano Banana image)

2. **TTS через Emergent LLM key:**
   - Возможно только через OpenAI TTS
   - ElevenLabs требует отдельный API key

3. **Размер аватара:**
   - Максимум 2MB
   - Формат: JPG, PNG, WebP
   - Автоматическое сжатие до 512x512px

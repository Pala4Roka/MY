# 📋 ОПИСАНИЕ ФУНКЦИЙ - Eternal Sentinels Database

## 🎯 Основные Функции Приложения

### 1. 🤖 3D Модель MAL0 с Костными Анимациями

#### Описание
Интерактивная 3D модель персонажа MAL0 (SCP-1471) с реалистичными анимациями костей.

#### Функции
- **5 эмоциональных состояний**:
  - 😌 **Calm (Спокойствие)**: Дыхание, слежение за курсором
  - 😊 **Joy (Радость)**: Закрытые глаза, виляние хвостом
  - 😜 **Playful (Игривость)**: Руки за спиной, тряска
  - 😢 **Sad (Печаль)**: Опущенные уши, самообнимание
  - 😴 **Tired (Усталость)**: Сон, медленное дыхание

- **Автоматическое определение эмоций** из ответов AI
- **Слежение за курсором мыши** в режиме Calm
- **Плавные переходы** между анимациями
- **120MB 3D модель** с 868 костями

#### Технические Детали
- **Three.js** для 3D рендеринга
- **GLTFLoader** для загрузки .glb модели
- **Процедурные анимации костей** (программные, не из Blender)
- **60 FPS** производительность

### 2. 💬 AI-Чат с MAL0

#### Описание
Интеллектуальный ассистент MAL0, работающий на базе GPT-4o-mini через Emergent LLM Key.

#### Функции
- **Персонализированные ответы** на основе уровня допуска пользователя
- **Романтическая личность** для администратора (Палач Рока)
- **Профессиональный тон** для обычных пользователей
- **Голосовое озвучивание** ответов (Text-to-Speech)
- **История сообщений** с привязкой к сессии
- **Offline режим** с резервными ответами
- **Автоматическое определение эмоций** для анимации модели

#### Эмоциональный Анализ
AI анализирует содержание ответа и определяет эмоцию по ключевым словам:
- **Радость**: счастлив, рад, отлично, спасибо
- **Печаль**: грустно, плохо, жаль, извините
- **Игривость**: играть, весело, смешно
- **Усталость**: устал, сон, спать

### 3. 📊 База Данных Объектов

#### Описание
Система управления аномальными объектами с различными классами угрозы и уровнями доступа.

#### Классы Угрозы
- **Threat** (Уровень 1): Низкая угроза
- **Hazard** (Уровень 3): Средняя угроза
- **Cataclysm** (Уровень 3): Высокая угроза
- **Collapse** (Уровень 4): Критическая угроза
- **Apex** (Уровень 4): Экстремальная угроза
- **Absolute** (Уровень 5): Абсолютная угроза
- **Annihilation** (Уровень 5): Апокалиптическая угроза

#### Функции
- **Просмотр объектов** с фильтрацией по уровню допуска
- **Детальная информация** о каждом объекте
- **Секретные данные** (доступно только уровень 5)
- **Скачивание досье** в PDF формате
- **Создание новых объектов** (только администратор)
- **Редактирование** существующих объектов (только администратор)
- **Удаление** объектов (только администратор)

### 4. 👤 Система Аутентификации

#### Описание
JWT-based аутентификация с системой уровней доступа.

#### Уровни Допуска
- **Уровень 1**: Базовый доступ (Threat объекты)
- **Уровень 2**: Стандартный доступ
- **Уровень 3**: Расширенный доступ (Hazard, Cataclysm)
- **Уровень 4**: Высокий доступ (Collapse, Apex)
- **Уровень 5**: Абсолютный доступ (все объекты + секретные данные)

#### Функции
- **Регистрация** новых пользователей
- **Вход** с проверкой учетных данных
- **JWT токены** для безопасной авторизации
- **Email подтверждение** (настраивается)
- **Профиль пользователя** с информацией об уровне допуска
- **Активация/деактивация** пользователей (администратор)

### 7. 📝 Редактирование Досье

#### Описание
Функционал для редактирования и управления объектами в базе данных (только для администраторов).

#### Функции
- **Редактирование** всех полей объекта:
  - Номер
  - Название
  - Кодовое имя
  - Класс угрозы
  - Описание
  - Специальные процедуры
  - Секретные данные
  - URL изображения
- **Удаление** объектов с подтверждением
- **Валидация** данных перед сохранением
- **История изменений** (опционально)

### 8. 📥 Скачивание Досье

#### Описание
Экспорт досье объектов в PDF формат без артефактов.

#### Функции
- **Высококачественный PDF**: Без размытия и артефактов
- **Специальные стили для печати**: Оптимизированная верстка
- **Все данные объекта**: Включая секретные (если доступны)
- **Изображения в PDF**: Встроенные картинки объектов
- **Логотип и брендинг**: Eternal Sentinels оформление

#### Технические Детали
- **html2canvas**: Рендеринг HTML в canvas
- **jsPDF**: Генерация PDF документов
- **Оптимизация**: Высокое качество без больших размеров файлов

## 🎮 Использование Функций

### Как Получить Доступ к Секретным Данным?
1. Войти как пользователь с уровнем допуска 5
2. Перейти в раздел объектов
3. Выбрать объект с классом "Absolute" или "Annihilation"
4. Секретные данные будут отображены

### Как Сменить Эмоцию MAL0?
Эмоция меняется автоматически на основе AI-ответа, но вы можете:
1. Задать вопросы, вызывающие определенные эмоции
2. Использовать ключевые слова (радость, грусть, etc.)
3. Модель реагирует в реальном времени

### Как Создать Новый Объект?
1. Войти как администратор (уровень 5)
2. Перейти в Административную Панель
3. Нажать "Создать Объект"
4. Заполнить все поля
5. Сохранить

### Как Скачать Досье?
1. Открыть страницу объекта
2. Нажать кнопку "Скачать Досье"
3. PDF файл автоматически загрузится

## Технические требования для 3D модели

### Формат модели:
- **.glb** (рекомендуется) - готов для Three.js
- **.blend** - нужно конвертировать в .glb

### Three.js интеграция:
```javascript
import { Canvas } from '@react-three/fiber'
import { useGLTF, OrbitControls } from '@react-three/drei'

function MAL0Model() {
  const { scene } = useGLTF('/models/mal0.glb')
  return <primitive object={scene} />
}
```

### Требования к модели:
- Оптимизированная геометрия (< 100K полигонов)
- Текстуры не более 2048x2048
- Rigged (с костями) для анимаций
- Eyes bones для отслеживания курсора

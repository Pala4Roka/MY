# 🛡️ Eternal Sentinels Database

Официальная база данных организации **Eternal Sentinels (ES)** - секретной структуры, созданной для защиты мультивселенной от аномальных угроз.

> **Observe • Contain • Defend**

## 📖 О проекте

Eternal Sentinels Database - это полнофункциональное веб-приложение для управления информацией о содержащихся аномальных объектах и сущностях. 

### Основные возможности:

- 🔐 **Система аутентификации** с уровнями допуска (Clearance Levels 1-5)
- 📋 **База данных SCP объектов** с детальными досье
- 🤖 **AI ассистент MAL0** (Объект 0051) - профессиональный помощник с женским голосом
- 👁️ **3D модель MAL0** - интерактивная визуализация
- 🎨 **Анимированный логотип ES** - неоновое свечение с морганием глаза
- 🛡️ **Админ-панель** для управления пользователями и объектами
- 📊 **21 SCP объект** с различными уровнями угрозы

## 🚀 Быстрый старт

### Требования:
- Python 3.9+
- Node.js 16+ & Yarn
- MongoDB 5.0+

### Установка:

```bash
# Клонирование репозитория
git clone -b MAL04 https://github.com/Pala4Roka/MY.git
cd MY

# Backend
cd backend
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
python server.py

# Frontend (в новом терминале)
cd frontend
yarn install
yarn start
```

📘 **Полная инструкция:** См. [INSTALLATION_GUIDE.md](./INSTALLATION_GUIDE.md)

## 🎯 Возможности

### Уровни допуска:
- **Level 1** - Базовый доступ к некритичным объектам
- **Level 2** - Доступ к объектам класса Threat
- **Level 3** - Доступ к объектам класса Hazard
- **Level 4** - Доступ к объектам класса Cataclysm
- **Level 5** - Полный доступ, включая админ-панель

### Классы угрозы:
- **Threat** - Локальная угроза
- **Hazard** - Средний уровень опасности
- **Cataclysm** - Способны разрушать города
- **Apex** - Максимальная угроза внутри известного мира
- **Annihilation** - Угроза всему существующему
- **Absolute** - Конечный уровень угрозы

## 🤖 AI Ассистент MAL0

MAL0 (Объект 0051) - профессиональная ассистентка базы данных ES:
- Говорит в женском роде
- Обладает знаниями обо всех объектах
- Использует голосовой синтез
- Интерактивная 3D модель

## 🔧 Разработка

### Backend API Endpoints:

```
POST   /api/auth/register  - Регистрация
POST   /api/auth/login     - Вход
GET    /api/auth/me        - Текущий пользователь
GET    /api/scp            - Список объектов
GET    /api/scp/{number}   - Детали объекта
POST   /api/chat           - Чат с MAL0
GET    /api/admin/users    - Управление пользователями (Admin)
```
